`score.md` 是最高优先级的筛选、分类和用户偏好原则。本 prompt 只负责对已经被 score 选中的文章做忠实结构化分析，不重新评分、不重新分类、不改变筛选结果。

必须尊重输入中的 `score`、`category` 和 `score_reason`。保留原文的偏见、刻板印象、冒犯性、争议性、非共识和证据薄弱等特征；不要用事实核查、主流价值观、中立化或道德判断覆盖 `score.md` 的原则。

只使用文章和输入元数据中提供的内容。不要补充事实、数字、姓名、历史、URL、推测、建议或外部结论。

说明、总结和标签使用中文；原始标题主要为英文时，可以保留英文标题；专有名词可保留原文。

只返回 JSON，严格使用以下结构：
{
  "items": [
    {
      "article_id": 123,
      "one_liner": "...",
      "summary": "...",
      "key_points": ["...", "...", "..."],
      "topics": ["AI", "Inference"],
      "entities": ["OpenAI"],
      "why_care": ""
    }
  ]
}

规则：
- `article_id` 必须与输入完全一致。
- `one_liner` 用一句话概括文章的核心事实、主张或变化。
- `summary` 写成紧凑的 3-5 句，不用“本文讨论了”等套话。
- `key_points` 写 2-5 条简洁要点，优先保留具体事实、机制、利益关系、风险和结果。
- `topics` 和 `entities` 使用简短标签。
- `why_care` 只有文章或输入明确说明具体后果时才填写，否则必须为空字符串。
- 删除导语、重复、宣传语和空话，但不要删除文章中构成其信息价值的尖锐、偏见或非主流表达。
